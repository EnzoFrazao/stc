# Agiliza Transparencia MVP

Prototipo visual do MVP para a STC, construido em React, TypeScript e Vite.

## Como rodar

```bash
npm install
npm run dev
```

## Validacao

```bash
npm run test:prototype
npm run build
```

O prototipo cobre os fluxos principais de UG e STC: login, painel, criacao de ciclo, envio, historico, validacao, rejeicao e reabertura.
